# CentrasFlow AI - Интеллектуальная система управления задачами

CentrasFlow AI — это инновационная Kanban-система с встроенным искусственным интеллектом для управления проектами и задачами Centras Group.

## Обзор

Система использует Google Gemini AI для автоматизации бизнес-процессов, декомпозиции задач и предиктивной аналитики.

### Ключевые возможности

*   **Умное прогнозирование:** AI анализирует исторические данные для предсказания времени выполнения.
*   **Автоматическая приоритизация:** Динамическое изменение приоритетов на основе бизнес-целей.
*   **Интеллектуальные инсайты:** Выявление паттернов и узких мест.
*   **AI Ассистенты:** Режимы "Бизнес-аналитик", "Декомпозиция задач", "Аналитика для администратора".

## Технологический стек

*   **Database:** Supabase PostgreSQL
*   **Backend:** Supabase Edge Functions + REST API
*   **AI Engine:** Google Gemini API
*   **Deployment:** Railway

## Структура проекта

*   `supabase/migrations`: SQL миграции для создания схемы базы данных.
*   `supabase/functions`: Исходный код Edge Functions (например, `ai-assistant`).

## Установка и запуск

### Предварительные требования

1.  Установленный Supabase CLI.
2.  Аккаунт Supabase и Railway.
3.  Google Gemini API Key.

### Локальная разработка

1.  Запустите Supabase локально:
    ```bash
    supabase start
    ```

2.  Настройте переменные окружения:
    Создайте файл `.env` с ключом `GEMINI_API_KEY`.

3.  Запустите Edge Function локально:
    ```bash
    supabase functions serve ai-assistant --no-verify-jwt
    ```

### Развертывание

Проект настроен для развертывания через GitHub Actions на Railway.

См. документацию Railway и Supabase для настройки production окружения.

## Архитектура базы данных

База данных разделена на следующие схемы:
*   `app_auth`: Пользователи и организации.
*   `app_projects`: Проекты и доски.
*   `app_tasks`: Задачи, комментарии и связи.
*   `app_analytics`: Метрики, KPI и инсайты.
*   `app_ai`: Конфигурация AI ассистентов и логи.

Подробности см. в файлах миграций.
